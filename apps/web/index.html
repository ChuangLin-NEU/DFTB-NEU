DFTB 简介 · DFTB+ 使用要点 · 本软件操作路径

一、什么是 DFTB

DFTB（Density Functional Tight Binding）是一种基于密度泛函理论参数化的紧束缚方法：在保留量子力学图像的同时，用预先拟合的积分表大幅降低计算量，适合固体物理教学、较大体系与高通量初筛。

  • 相对全电子 / 平面波 DFT：速度快、参数依赖明确，适合课堂演示与趋势分析。
  • 常见任务：SCC 单点、几何优化、能带与态密度、分子激发（Casida）、短程分子动力学等。
  • 结果质量取决于 SK 参数集（如 3ob、pbc）与几何/k 点设置是否合理。
二、DFTB+ 怎么用

DFTB+ 是开源 DFTB 引擎。一次计算通常需要：结构文件（GEN / POSCAR）+ 输入脚本（HSD）+ 对应元素的 Slater–Koster 参数。

  1. Geometry：给出原子坐标与边界条件（分子簇或周期晶体）。
  2. Hamiltonian：选择 DFTB/xTB、是否 SCC、k 点网格、填充温度等。
  3. Driver：单点、几何优化、分子动力学等。
  4. Analysis：能带路径（Klines）、态密度、激发态（Casida）等后处理块。
  5. 运行 dftb+ 后，从 detailed.out、band.out、EXC.DAT 等读取结果并绘图。

本软件会根据自然语言自动生成输入文件（HSD），也可以上传自己写的 HSD；并在本机 WSL 隔离环境中调用 DFTB+。生成或上传后可直接编辑，再确认计算。

三、本软件怎么用
  1. 登录：学号 + 教师公布的本堂密码。
  2. 环境：打开「环境」页，完成 WSL2 / DFTB+ 部署与测试校验（仅首次或更换电脑）。
  3. 计算：在首页或「计算」页用一句话描述任务；可点「举例」填充。也可以直接上传自己写的 HSD。周期体系可上传 POSCAR/GEN，或由 AI 自动获取结构。
  4. 确认计算：生成或上传 HSD 后，核对结构与输入，再点「确认计算」投到本机。
  5. 任务：在「任务」页查看进度、能量/收敛、能带·DOS 等图件，以及本地性能评估。
  6. 课程（可选）：固体物理课次可「一键复现」生成结构与输入，便于对照课堂内容。

推荐路径：首页输入 → 自动生成输入 → 确认计算 → 任务页看图。

核心能力

一体化路径：课次结构、自然语言、本机部署计算，以及数据分析与绘图。

  • 自然语言计算 描述任务 → 生成输入文件 → 确认后在本机 DFTB+ 运行
  • 课程课次 按固体物理课次载入结构与计算意图，更好理解课程
  • 结构来源 上传 POSCAR / GEN，或由 AI 从 Materials Project 数据库获取
  • 任务与绘图 跟踪作业进度，数据后处理分析与绘图

            手动部署
            

              
适用于一键下载 Ubuntu 很慢或失败的情况。先用国内镜像装好 Ubuntu，再回到本页完成 DFTB+ 安装。


              
1. 启用 WSL（仅首次）

              
以管理员身份打开 PowerShell，执行：

              
wsl --install --no-distribution
wsl --set-default-version 2

              
若提示重启，请先重启电脑，再继续。


              
2. 用国内镜像下载 Ubuntu 22.04 rootfs

              
任选其一（约 325 MB，amd64）：

              
    
                
  • 清华大学镜像
    • 
                
  • 中科大镜像
    • 
              

              
或在 PowerShell 中下载到「下载」文件夹：

              
$url = "https://mirrors.tuna.tsinghua.edu.cn/ubuntu-cloud-images/wsl/jammy/current/ubuntu-jammy-wsl-amd64-ubuntu22.04lts.rootfs.tar.gz"
$out = "$env:USERPROFILE\Downloads\ubuntu-jammy-wsl.rootfs.tar.gz"
Invoke-WebRequest -Uri $url -OutFile $out


              
3. 导入为 WSL 发行版

              
$tar = "$env:USERPROFILE\Downloads\ubuntu-jammy-wsl.rootfs.tar.gz"
$dir = "$env:LOCALAPPDATA\WSL\Ubuntu-22.04"
New-Item -ItemType Directory -Force -Path $dir | Out-Null
wsl --import Ubuntu-22.04 $dir $tar --version 2
wsl --set-default Ubuntu-22.04


              
4. 创建日常用户（推荐）

              
wsl -d Ubuntu-22.04 -u root -- bash -lc "useradd -m -s /bin/bash neu123 && echo 'neu123:neu123' | chpasswd && usermod -aG sudo neu123 && echo -e '[user]\ndefault=neu123' > /etc/wsl.conf"
wsl --terminate Ubuntu-22.04
wsl -d Ubuntu-22.04 -e whoami

              
最后一行应输出 neu123。可将密码改成自己的。


              
5. 回到本软件完成 DFTB+

              
    
                
  1. 本页点击 刷新，确认 WSL2 就绪。
    2. 
                
  2. 再点 部署到本机（此时一般不再下载 Ubuntu，只安装 DFTB+ / SK / 测试校验）。
    3. 
                
  3. 等待三项全部通过。
    4. 
              


              
6. 可选核对

              
wsl -d Ubuntu-22.04 -e bash -lc "~/.dftb-neu/envs/dftbplus/bin/dftb+ --version"
