# DFTB 工作台 · 教师手册

## 产品定位

**DFTB+ 本机计算工作台**：Windows 桌面壳 + 本机 API + WSL2 隔离环境，面向科研与教学。教学组织使用教师端发布本堂密码并监管会话。

## 课前准备

1. 确认课堂服务中心已启动（见 [课堂中心.md](./课堂中心.md)）。
2. 打开 **教师端**（安装包已预置服务地址与教师凭证，界面不需填写）。
3. 发布本堂密码，告知学生；可用「复制」短暂查看刚发布的完整密码。
4. 学生用**学号 + 本堂密码**登录后，自行「部署到本机」。
5. 课程结束后点击「结束本堂」清空口令，或更换新密码；旧短密码会话失效。

## 建议课时流程

1. **环境**（15 min）：解读 WSL / DFTB+ / 冒烟三项状态。
2. **课程训练**：按「课程」页固体物理课次顺序（晶体 SCC → 能带 → … → 科研综合）。
3. **自由计算**：自然语言描述任务，确认 HSD 后投递。
4. **成稿**：在「任务」页导出方法摘要（Markdown/HTML），核对 SK 与能力族表述。

## 固体物理课次（预置）

1. 晶体与倒格矢 — Si SCC  
2. 布里渊区与能带 — Si 能带/DOS  
3. 电荷自洽与收敛 — H₂O 几何优化  
4. 二维材料 — 石墨烯能带  
5. 缺陷与局域态 — 石墨烯空位  
6. 晶格振动入门 — 声子相关输入  
7. 分子动力学 — BOMD  
8. 科研综合课题 — 自选结构 + 方法摘要  

## 评分建议

| 项 | 观察点 |
|----|--------|
| 输入 | HSD 是否与意图一致（Driver / Hamiltonian） |
| 计算 | 冒烟或作业完成，日志无致命错误 |
| 分析 | 能指认总能量 / 能带或轨迹相关输出 |
| 文稿 | 方法摘要含 DFTB+、SK、能力族 |

## 运维备注

- 数据根：WSL 内 `$HOME/.dftb-neu`；Windows 配置 `%LOCALAPPDATA%\dftb-neu`。
- 文案规范：界面使用「部署到本机 / 隔离部署」，避免「一键」等口语。
- 「长期」会话 = 教师永久凭证登录，换本堂密码时保留。
