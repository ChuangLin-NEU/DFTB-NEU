# 课堂中心

## 角色

| 端 | 功能 |
|----|------|
| **学生端** | 学号 + 本堂密码登录；DFTB 部署 / 课程 / 计算 |
| **教师端** | 发布本堂密码、监管在线学生、结束本堂；**无计算** |
| **课堂中心** | 鉴权、会话、LLM/MP 代理 |

默认公网地址（安装包预置，学生无需 Tailscale）：`https://desktop-ibhgp7g.tailcc9705.ts.net`（Tailscale Funnel 固定 HTTPS）。若更换域名，请同步更新学生端 / 教师端配置后重打包。

## 登录规则

- 学生输入：**学号** + **口令**
- 口令可以是：
  1. 教师本堂公布的短密码；或
  2. 教师永久凭证（由运维配置，不在学生界面展示）
- 可同时存在多个本堂短密码；学生使用任一有效口令即可登录
- 吊销单个短密码后：仅对应该口令的会话失效
- 「清空全部」清空全部短密码并注销短密码会话；永久凭证（长期）会话保留

## 教师端

`apps/teacher_web` + `packaging/windows/teacher-electron`

1. 打开教师端（服务地址与教师凭证由安装包预置）  
2. 可多次「发布本堂密码」叠加多个口令；列表中可复制或单独吊销  
3. 学生列表自动刷新：学号、活跃状态、登录/过期时间、今日 LLM、设备、注销  
4. 结课：点击「结束本堂」清空全部口令并吊销短密码会话  

若需更换中心地址：编辑教师端 `config.json` 的 `hubUrl`，或设置环境变量 `DFTB_CLASS_HUB_URL`。

见 `scripts/run_classroom_hub.sh` / `scripts/start_classroom_hub_4060.ps1`。教师凭证与管理员密钥由环境变量配置，勿写入对外文档明文。
