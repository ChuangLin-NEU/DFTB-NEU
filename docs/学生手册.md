# DFTB 工作台 · 学生 / 科研用户手册

## 安装

运行 `DFTB_Neu_Setup_*.exe`，按界面完成安装后打开「DFTB 工作台」。

## 推荐流程

1. **登录**：填写学号与教师公布的本堂密码。
2. **环境**：在「环境」页执行「部署到本机」（Windows 需启用 WSL2）。须 WSL、DFTB+、冒烟校验三项均通过。
3. **课程**：在「课程」页按固体物理课次载入结构与计算意图；或直接进入「计算」自由描述任务。
4. **任务**：在「任务」页查看进度、观测量与方法摘要导出。

## 部署说明

- 写入用户目录 `~/.dftb-neu`（隔离环境，不改系统全局）。
- 首次可能需管理员确认启用 WSL2；若系统提示重启，重启后再次点击「部署到本机」。
- 部署包含 micromamba 环境、SK 参数与 H₂O 几何优化冒烟校验。

## 计算说明

- 周期体系（能带、缺陷、声子等）必须提供 POSCAR/GEN；可从课程载入或 Materials Project 拉取。
- 分子示例（几何优化、Casida、BOMD 等）可在无结构时使用内置水分子。
- 「导出方法摘要」生成方法段与课堂摘要，并非完整论文。

## 设置

课堂服务地址由安装包预置。日常只需学号与本堂密码。

## 故障排查

- **无法启动**：查看 `%APPDATA%\DFTB工作台\backend.log`。
- **部署失败**：在环境页查看三项状态与日志，确认 WSL 就绪后再次部署。
- **无法登录**：向教师核对本堂密码，并确认课堂服务可访问。
